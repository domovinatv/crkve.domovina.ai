## Naredbe

```bash

export HTTP_PROXY=http://127.0.0.1:9 HTTPS_PROXY=http://127.0.0.1:9 ALL_PROXY=http://127.0.0.1:9

uv run python "$SCRATCH/s3diff.py" "$SCRATCH/baseline-s2.db" "$SCRATCH/after-s3.db"
```

`s3diff.py` (scratchpad, jednokratan) spaja **po slugu**, nikad po `id`: za svaku crkvu
uspoređuje `(parishes.slug preko parish_id, is_parish_church)`, `heritage_id`, `year_built`,
`kind`, `name`, `wikidata_id`, `commons_image`; za pravne osobe `kind` i `name`; skupove
slugova u obje tablice; `count(*) from heritage_unmatched`. Udaljenost je haversine između
`churches.lat/lng` i `parishes.lat/lng`.
